# GUI 补充规范

继承根目录和 `src/AGENTS.md`。

- widgets、scene/items、Qt models 仅在主线程访问；耗时解析、算法和导出通过应用服务在后台执行。
- 长循环的暂停/取消使用线程安全控制令牌和条件变量，不能只依赖 worker 的排队 slot。
- 控件、成员、局部变量、signal/slot、事件负载和 lambda 捕获都需说明用途及线程归属；完整注释参数和输出。
- 只读快照标识 dataset/run/stage/revision；丢弃过期消息，最终状态只提交一次，预览缓存保持有界。
- 算法参数来自共享有效配置，GUI 不维护另一套默认值；暂停时锁定算法参数。
- 图元使用稳定 ID 和分块/LOD；屏幕坐标不能反向污染领域数据，标签不重复翻转。
- 界面只读查看布局，不加入单元手动编辑。交互或状态变化同步更新 GUI 设计及 Qt Test 场景。
- 关闭时协作取消并等待安全结束，禁止强制终止线程；导出失败不篡改主算法状态。
