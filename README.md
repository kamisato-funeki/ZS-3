## 使用约定

- 需求编号为 `REQ-*`，测试编号为 `TC-*`；接口名称是设计名称，不是第三方库 API 的复制。
- BookShelf 主链路使用现有数据集；LEF/DEF 是适配链路。两者进入同一领域模型，算法不依赖具体文件格式。
- GUI 首先面向 Linux，采用 Qt Widgets；Qt 为可选依赖，核心与命令行可无桌面运行。
- 所有算法和 GUI 测试均为“待实现、待执行”；本次只检查文档本身，不报告虚构的运行效果。
- 单元手动编辑、布线、时序驱动优化、完整工业级 DEF 写回、多高度标准单元合法化不属于本版范围。

## 文档完成标准

资料要求能够追踪到需求、模块与测试；接口单位、状态、错误及文件格式一致；算法给出可计算定义；GUI 给出操作和并发规则；每项验收均有判据。工程目录已按[目录设计](docs/03-项目目录与模块设计.md)搭建；空目录使用 `.gitkeep` 保留，构建及运行产物由 `.gitignore` 排除。
