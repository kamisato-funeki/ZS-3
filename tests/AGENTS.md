# 测试补充规范

继承根目录 `AGENTS.md`。

- 根据 `docs/09-测试用例与验收方案.md` 关联测试编号与需求，断言行为和可计算结果，不复写实现当判定器。
- 夹具、测试变量、常量、字段、辅助函数和业务 lambda 同样必须有用途、输入输出与单位注释。
- 数值测试注明精度和公式；线程测试使用受控屏障，避免任意等待制造偶然通过。
- 拓扑、单位、梯度、固定性和合法性优先独立核对；GUI 用 Qt Test，外部回读结果注明工具版本。
- 修改文档/配置只执行相应语法、链接和加载检查；不为低影响文字更改编写无意义软件测试。
- 不把大型参考数据、运行产物、凭据或测试缓存纳入仓库；尚无实现时保留用例设计，不伪造测试程序或通过记录。
