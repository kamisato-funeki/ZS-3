# 公共接口补充规范

继承根目录 `AGENTS.md`。

- `include/placement/` 只暴露稳定领域类型和服务契约；实现细节放 `src/`，不暴露 Qt 控件或第三方内部类型。
- 每个类型、字段、常量、枚举值都写语义、单位、范围及适用约束；ID、坐标、方向和终态不能混用基本数值类型暗示含义。
- 所有公共函数使用完整 Doxygen 注释，逐个覆盖参数方向、输出、失败、所有权、有效期及线程约束；禁止无说明的可空指针或隐式输出。
- tuple/pair 必须逐项说明；有业务字段含义的返回值优先命名结构体。
- 修改接口先核对 `docs/04-总体技术与接口设计.md` 及调用方，随同更新文档和相关测试。
- 公共头文件应可独立包含，使用必要的 include 与前置声明，不写全局 `using namespace`。
