# 需求规格说明书

版本：1.0。导航：[首页](../README.md) · [总体接口](04-总体技术与接口设计.md) · [测试追踪](09-测试用例与验收方案.md)。

## 1. 使用者与工作流程

使用者为课程开发者、算法实验者和验收人员。基本流程为：选择输入 → 审计与初始布局准备 → 配置 → 全局布局 → 查看与双方式导出 → 宏合法化 → 标准单元合法化 → 独立检查 → 阶段对比与结果导出。命令行和 GUI 采用相同参数语义与核心算法。

本版不包含制造级 DRC、时序分析、布线、单元交互编辑、跨会话优化器断点续算，以及任意形状/多高度标准单元合法化。相关输入不得静默当作已支持。

## 2. 功能需求

所有下表需求均为本版必需；受支持子集限制时必须产生明确诊断。

| 编号 | 需求与可观察行为 |
|---|---|
| REQ-IN-01 | 从 AUX 关联的 nodes/nets/pl/scl/wts 加载数据；支持注释、空白和空权重文件；核对数量、重复名称及引用完整性 |
| REQ-IN-02 | 从 LEF/DEF 的站点、宏定义、实例、行、引脚、网络、放置状态、矩形阻挡映射统一模型；缺宏/引脚及不支持约束明确报错 |
| REQ-IN-03 | 统一坐标、方向、单位、固定状态和初始位置；对缺失或不可用初始位置执行可重现准备，固定对象保持原值 |
| REQ-GP-01 | 用平滑线长与静电密度优化标准单元、可移动宏和 filler；filler 不参与网络与最终实例输出 |
| REQ-GP-02 | 使用 Nesterov、冻结参数的回溯及动态 λ/γ；记录真实 HPWL、目标、溢出率及终止原因 |
| REQ-GP-03 | 容量不足、非有限数、零分母、不可接受步长与最大迭代各有独立处理；不得伪报收敛 |
| REQ-VIS-01 | CImg 输出 BMP，显示 core/chip、标准单元、宏、固定对象和图例，坐标正确且比例一致 |
| REQ-VIS-02 | 输出 GDSII，定义物理比例、精度和图层，可在 KLayout 打开并回读核对几何 |
| REQ-VIS-03 | 提供初始、全局、宏合法、最终阶段快照与指标、合法性状态、参数及随机种子 |
| REQ-LG-01 | 独立报告重叠、越界、固定对象变化、行/站点/方向不匹配及不支持对象 |
| REQ-LG-02 | 对可移动宏执行受边界和固定障碍限制的模拟退火；有合法解才发布宏合法阶段，否则返回失败诊断 |
| REQ-LG-03 | 宏合法后切分行区间，采用 Abacus 放置单高度标准单元，消除重叠并完成行与站点对齐 |
| REQ-LG-04 | 最终结果独立复检；修复失败不覆盖上一个成功阶段，原输入及固定状态不变 |
| REQ-UI-01 | GUI 提供文件选择、数据统计、参数校验和任务阶段选择；运行时锁定输入及算法参数 |
| REQ-UI-02 | 支持缩放、平移、选择、属性、名称定位、网络高亮、图层切换和违规定位 |
| REQ-UI-03 | 支持启动、暂停、继续、取消、重新运行及协作关闭；解析和导出支持取消但不支持暂停 |
| REQ-UI-04 | 后台执行耗时任务；只读快照有界传递、过期消息隔离、默认最高 5 Hz 预览，完成结果必达 |
| REQ-UI-05 | 提供进度、日志和 HPWL/溢出曲线；阶段双视图同步导航并展示指标差值 |
| REQ-UI-06 | 支持选定阶段的结果/图片/GDS/报告导出；暂停时导出完整快照，注明非最终结果 |

## 3. 非功能与工程需求

| 编号 | 要求 | 验证方法 |
|---|---|---|
| REQ-NF-01 | 核心不依赖 Qt；可关闭 GUI 构建并在无显示环境运行 CImg 导出 | 无 Qt 配置路径与无 DISPLAY 场景 |
| REQ-NF-02 | 相同输入、配置、依赖版本和单线程种子下结果可重现；浮点结果按误差比较 | 两次运行指标、坐标及终止原因对比 |
| REQ-NF-03 | 大数据不预创建全部引脚/网络图元，不积累每轮完整快照 | 对 adaptec4 记录内存和缓存数量 |
| REQ-NF-04 | GUI 不在主线程执行解析、算法和大型文件写出；所有控件仅主线程访问 | 线程断言、运行中交互与取消测试 |
| REQ-NF-05 | 输出附带版本、输入指纹、参数、单位和任务身份；错误不遗留伪完整结果 | 元数据审计和故障注入 |
| REQ-NF-06 | 每个功能需求关联测试及验收证据，所有外部依赖登记许可证和版本 | 追踪矩阵及依赖表审核 |

默认交互预算是设计目标而非实测承诺：中等机器上输入操作反馈目标不超过 100 ms，视图响应 P95 目标不超过 200 ms；超限需报告，并通过降采样/LOD 调整后重测。加载、优化总耗时不制定脱离硬件的硬阈值。

## 4. 输入适用范围

BookShelf 支持水平 CoreRow、多 SubrowOrigin、站点步长、固定终端及矩形实例。所有名称区分大小写，文件中的名称映射到稳定 ID。`.wts` 无条目时默认网络权重 1；显式权重须非负且有限。

LEF/DEF 本版消费：LEF UNITS、SITE、MACRO CLASS/SIZE/ORIGIN/SYMMETRY、PIN PORT 的矩形/多边形几何；DEF UNITS、矩形 DIEAREA、ROW、COMPONENTS、PINS、NETS、矩形 placement BLOCKAGES。引脚以各有效几何包围盒中心作为线长点，记录这一近似。非矩形 DIEAREA、REGIONS/GROUPS 约束、软/部分阻挡、多高度标准单元等返回不支持错误；布线、via、轨道等不参与布局的数据可以忽略，但列入加载摘要。未放置顶层端口因缺少锚点而报错。

LEF/DEF 是否配套必须核对实例 master、site 和 pin 名称，不能只根据目录位置认定匹配。现有 `cn.lef` 与 `ispd19_test1.input.def` 为候选适配数据，完整核对之前不标为通过。

## 5. 输出和状态

每次运行独占结果目录，保存有效配置、输入审计、四个阶段中的已完成快照、迭代指标、违规报告、图像和 GDS。中途取消、算法未收敛、合法化未找到解均可输出已完成结果，但必须标明原因。合法标识只能来自独立检查器；全局布局的低溢出率不代表无重叠。

导出采用临时文件完成后重命名；已有目标默认拒绝覆盖，用户显式指定覆盖后才替换。写失败、取消和空间不足返回错误并保留已有成功文件。

## 6. 需求变更规则

新增平台、手动编辑或扩大格式范围需同步更新接口、GUI 状态、测试和追踪矩阵。文档中的数值默认值集中定义在总体接口及对应算法章节，界面不得另设隐含默认值。
