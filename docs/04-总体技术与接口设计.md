## 2. 系统数据流

```text
BookShelf / LEF+DEF
        ↓ 读取和审计
DesignDatabase + InputAudit
        ↓ 初始位置准备
initial → GlobalPlacer → global
        → MacroLegalizer → macro_legal
        → RowPartitioner + Abacus → standard_legal
        ↓ 每阶段独立指标/合法性检查
只读 Snapshot → GUI / CImg / GDSII / JSON / CSV
```

宏合法失败不进入标准合法化。全局布局达到上限但数值有限时产生 `global` 快照，状态为 `max_iterations`；允许显式继续合法化尝试，完整流水线仍保留“全局未收敛”结论。失败、取消和导出状态独立于快照的几何合法状态。

## 3. 领域模型和不变量

所有 ID 使用 64 位无符号整数；同一数据集内稳定，由规范输入顺序赋值，名称索引不改变 ID。坐标与面积为 double，序列化时使用足够往返精度，非有限值禁止进入已提交快照。

| 类型 | 必需字段 | 不变量 |
|---|---|---|
| DesignDatabase | datasetId、unit、nodes/pins/nets/rows、regions、obstacles、输入指纹 | 拓扑只读；名称唯一、引用有效 |
| Node | id、name、kind、width/height、orientation、fixed、masterName | kind 为 standard/macro/terminal；尺寸非负，非端口实体尺寸严格为正 |
| Pin | id、nodeId 或 topPortId、netId、局部中心偏移 | 引脚归属唯一，偏移有限 |
| Net | id、name、pinIds、weight | weight≥0；空/单引脚网络线长为零并记统计 |
| RowSegment | id、y、height、xOrigin、siteWidth、sitePitch、numSites、orientation | 水平、pitch>0、siteWidth≤pitch；区间不重叠 |
| Region/Obstacle | 矩形集合、类型、对象来源 | 几何先做并集再计算面积，不重复扣除 |
| PositionState | 按 NodeId 对应的左下角、方向 | 固定对象位置与输入基线完全一致；方向在本版算法中不变 |
| Snapshot | datasetId/runId、stage、iteration、revision、位置、指标、状态 | 只读；引用同一只读数据库；不持有 filler |
| Violation | kind、objectIds、region、magnitude、message | 独立检查器产生；能从 GUI 定位 |
| Metrics | hpwl、weightedHpwl、overflow、densityEnergy、位移、耗时 | 无可比项用 null；不把无定义项写 0 |

Node 的几何、引脚和输入固定性由拓扑描述，位置保存在独立缓冲。filler 使用任务内临时 ID 空间，不写回数据库，也不改变原始计数。宏合法后标准合法化的锁定集合是运行上下文，不修改输入 `fixed` 字段。

### 3.1 坐标与单位

内部是数学坐标，x 向右、y 向上；矩形表示为半开区域 `[llx,urx)×[lly,ury)`，相接不算重叠。芯片显示区 ChipRegion 为 CoreRegion 和终端的包围盒；CoreRegion 是可放置行并集的包围盒，不等同于行并集本身。

BookShelf 数值保留为 design unit（DU）。可显式配置 `microns_per_du`，未提供时 GUI/报告标注 DU，GDS 使用 1 DU=1 μm 的显示映射并在 manifest 中标记 `physical_scale_known=false`。LEF/DEF 将 DBU 转为 μm，统一存储 1 DU=1 μm，绝不混用 DEF 整数和 LEF 小数。

内部标准单元宽度必须为 sitePitch 的整数倍，且 siteWidth=sitePitch；不满足者不纳入 Abacus 支持子集。几何尺度容差 εg=10⁻⁸×max(1,Core宽,Core高) DU；站点容差 εs=min(εg,10⁻⁶×pitch)，按行使用。碰撞、硬阻挡及边界判断统一使用 εc=min(εg,10⁻⁶×pmin) DU；pmin 是存在行时最小 sitePitch，无行时取 εg。εs 用于站点和行跨度对齐；εa=εg² 仅抑制面积浮点噪声。容差不作为坐标修正量；固定性仍按输入基线精确比较。

### 3.2 方向与引脚映射

内部引脚偏移相对未旋转单元中心。设偏移为 (u,v)，方向映射如下；奇数个 90° 旋转交换包围盒宽高，中心由当前左下角与朝向后的尺寸确定。

| N | S | W | E | FN | FS | FW | FE |
|---|---|---|---|---|---|---|---|
| (u,v) | (-u,-v) | (-v,u) | (v,-u) | (-u,v) | (u,-v) | (v,u) | (-v,-u) |

全局引脚点=当前中心+变换后的偏移。LEF 的 ORIGIN 和 PIN 几何先转换为统一 master 局部框，再生成中心偏移，禁止在实例阶段再次加 ORIGIN。DEF placement 点按 LEF/DEF 5.8 的 SIZE 规则对齐朝向变换后的包围盒左下角：先将 PIN 几何加 ORIGIN，归一化到 `[0,width]×[0,height]` 的 SIZE 框，再变换四角并平移使 bbox 左下角与 placement 点一致。原设计将 placement 点视为变换前坐标原点的表述有误，实施时据格式规范修正；见 [LEF/DEF 5.8 Language Reference，SIZE 与 ORIGIN](https://coriolis.lip6.fr/doc/lefdef/lefdefref/lefdefref.pdf)。BookShelf 的中心偏移、左下角位置和方向分别读取。资料 SCL 中出现的数值 Siteorient=1 按课程数据兼容规则映射 N，并记录原值与警告；其他未知数值报错。未来算法不旋转对象，输入方向若不满足合法行则返回不支持方向。

### 3.3 分类和初始位置

显式实例分类覆盖几何推断；LEF CLASS BLOCK 为 macro，CORE 且匹配单一行高为 standard。BookShelf 固定 terminal 保留 terminal 分类，其矩形作为障碍；其余匹配唯一行高者为 standard，不匹配者为 macro，并输出推断列表供审计。不得只凭名称猜测类别。

默认初始模式 `auto`：保留有限且位于 core 包围盒内的可移动位置；缺失或越界者用固定种子在可放置行并集中抽样中心，并确保物理包围盒在 core 包围盒内。完全聚集但在界内的输入加相对行高 0.01 的可重现扰动，再投影边界。该阶段允许重叠，不能称为合法布局。任一节点比 core 大则报不可行；固定节点不投影，core 外终端允许存在并纳入显示区。全局布局若初始溢出已达停止阈值，直接以当前完整初始状态完成，不做微扰或优化。

## 4. 应用接口契约

下表记录逻辑接口的稳定职责；对应 C++ 声明见 `include/placement/`。所有结果按实现约定为成功值或 `Error`，错误包含 code、message、context、recoverable，异常不能穿过线程入口。

| 接口 | 输入 | 输出 | 前后置条件 |
|---|---|---|---|
| LoadDesign | 输入描述、单位配置、CancelToken | 数据库、审计、原始位置 | 路径可读；仅验证成功才替换当前数据集 |
| PrepareInitial | 数据库、原始位置、初始配置 | initial 快照、调整记录 | 不改固定对象；位置有限 |
| RunGlobal | 数据库、初始快照、GPConfig、ControlToken、EventSink | global 快照与终止原因 | 拓扑不变；指标与坐标同一轮 |
| LegalizeMacros | global 快照、MacroConfig、控制/事件 | macro_legal 或诊断结果 | 成功宏之间及固定障碍零重叠 |
| PartitionRows | 数据库、宏合法快照 | 可用 RowInterval 集合 | 宏/固定障碍扣除，边界对齐站点 |
| LegalizeStandard | 宏快照、区间、AbacusConfig、控制/事件 | standard_legal 或失败 | 不动宏和输入固定对象 |
| CheckLegality | 数据库、任意快照、检查范围 | ViolationReport | 纯计算，无副作用 |
| ComputeMetrics | 数据库、快照、基准快照 | Metrics | HPWL 使用真实引脚位置 |
| ExportSnapshot | 快照、格式、路径、单位映射、CancelToken | 文件清单、校验摘要 | 原子提交；不因几何非法拒绝导出，但醒目标记 |
| CompareStages | 同 dataset 的两份快照 | 指标差及逐对象位移 | 跨 dataset 比较拒绝 |

EventSink 接收身份、阶段、序号、指标、状态和诊断；回调不操作 Qt，也不阻塞核心。ControlToken 包含 atomic cancel/pause、互斥量和条件变量；取消优先于暂停，暂停等待须能被取消唤醒。导出单独拥有令牌，允许与已暂停算法并行读取常量快照。

## 5. 配置默认值

配置采用 JSON，未知字段报错，CLI 显式参数覆盖文件，文件覆盖内建默认；最终有效配置完整保存。下面定义的是设计参数表，不是可执行配置文件。

| 参数 | 默认 | 范围/规则 |
|---|---|---|
| seed | 42 | uint64；空 macro_seed 时从 seed 派生 |
| initial_mode | auto | auto / preserve / random；preserve 对无效位置报错 |
| target_density | 0.80 | (0,1]；容量预检不通过则拒绝运行 |
| grid_nx/grid_ny | auto | 每维 32～512 的 2 次幂；规则见任务 5 |
| overflow_stop | 0.10 | [0,1)；连续 5 轮满足才成功收敛 |
| convergence_window | 5 | 审计字段固定为5；初始overflow已满足的直接完成例外优先 |
| max_iterations | 2000 | 正整数；达到上限单独标记 |
| backtrack_limit / shrink | 20 / 0.5 | limit>0；0<shrink<1 |
| fft_threads | 1 | 本版只接受 1，保证基线确定性 |
| lambda_update_min/max | 0.75 / 1.10 | 动态倍率界；lambda_min/max 绝对界另为 1e-8 / 1e8 |
| macro_sweeps / moves_per_macro | 100 / 20 | 正整数；宏候选预算为宏数×sweeps×每宏移动数 |
| macro_seed | derived | 单独记录可复现派生值 |
| abacus_candidate_rows | all | 按垂直距离递增搜索、代价下界剪枝 |
| preview_hz | 5 | [1,10]；只限制预览，不丢终态 |
| image_width / margin | 1600 / 24 px | 宽 256～8192；高按比例计算，上限 8192 |
| gds_dbu_um | 0.001 μm | >0；超出坐标范围则报错，不静默缩放 |

λ/γ、密度核、SA 温度和代价细节见任务 5/7，GUI 显示同一参数源，不另设一套默认。高级参数可放折叠面板，仍进入 effective-config。

## 6. 结果格式与版本

所有 JSON 根字段含 `schemaVersion=1`。manifest 含 datasetId、runId、输入路径/指纹、软件/依赖版本、seed、单位来源、配置文件路径、各阶段状态和输出清单。placement 含 stage、iteration、revision、nodeId/name、llx/lly、orientation、termination、legalitySummary，filler 不写出。重载需原始输入指纹匹配；只载快照不支持恢复优化器动量。

metrics.csv 表头为 run_id、stage、iteration、revision、elapsed_ms、hpwl、weighted_hpwl、overflow、density_energy、lambda、gamma、step、status。缺省值留空，UTF-8，十进制小数点固定为点，不受 GUI locale 影响。密度能量在网格、γ或 λ 改变时不跨条件声称单调可比。

violations.json 含 checkedSnapshotIdentity、scope、countByType、records、truncated、totalCount；记录上限 10000，完整计数继续统计，GUI 不因截断显示“零违规”。events.jsonl 每行一个事件，记录单调序号与 UTC 时间，界面按本地时区显示。

CLI 子命令 `inspect`、`run`、`check`、`export` 已实现。输入以 `--aux FILE` 或一个/多个 `--lef FILE --def FILE` 指定；`--config FILE` 加载 JSON，`--set key=value` 设置高级参数。run 支持 `--snapshot FILE`、`--stage global|macro|standard|all`、`--output DIR` 和 `--continue-unconverged`；export 可用 `--overwrite` 显式覆盖目标文件。退出码：0 完成且请求条件满足；2 输入/配置错误；3 未收敛/未找到合法解；4 内部数值或 I/O 错误；130 取消。仅 inspect/export 成功不意味着布局合法。

## 7. 错误与恢复

| code | 场景 | 对策 |
|---|---|---|
| INPUT_INVALID / REFERENCE_MISSING | 格式、计数、宏或引脚引用问题 | 保留旧数据集，显示文件位置 |
| UNSUPPORTED | 非支持约束、方向、行或标准单元 | 列出具体对象，不自动降级为已支持 |
| CAPACITY_INFEASIBLE | 目标密度或明确几何容量不足 | 停止该阶段，报告面积/区间证据 |
| NUMERIC_FAILURE | NaN、梯度或步长失效 | 回滚到最后完整快照，记录轮次与参数 |
| MAX_ITERATIONS / NO_LEGAL_SOLUTION_FOUND | 未收敛或搜索未找到解 | 保留候选诊断；后者不等同数学不可行证明 |
| IO_FAILURE / OUTPUT_EXISTS | 导出失败或目标冲突 | 删除临时残件，原文件保持有效 |
| CANCELLED | 用户取消 | 唤醒暂停线程、丢弃未提交状态、允许重新运行 |

每个 runId 只发布一个终态；导出用独立 exportId，并绑定源 snapshot 身份，不参与覆盖算法终态。
