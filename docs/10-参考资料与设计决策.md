## 3. 原资料歧义与处理

| 问题 | 核对与采用的解释 | 影响 |
|---|---|---|
| 总任务主线使用BookShelf，而任务5开头写DEF | 统一领域模型，BookShelf主链路与LEF/DEF适配并存 | 不要求将所有输入先转DEF |
| 目标写HPWL但提供平滑梯度 | HPWL仅评价，WA作为优化线长 | 指标和目标字段分离 |
| 梯度排版将x/y偏导写成相加 | 梯度保留二维/2N维分量 | 不把方向压成标量 |
| 密度文字在ρ、φ之间混用，存在“对ρ求导得电场”的表述 | 正确链路为ρ→泊松方程→φ→E=−∇φ | 不把密度梯度当电势梯度 |
| 讲义DCT比例/频率省略边界和网格约定 | 固定cell-centered离散Neumann算子及正交DCT | 必须通过模式与往返测试 |
| 小单元拉伸与LengthScale未完整规定 | 使用保守平滑核和边界归一化 | 不直接抄不完整的面积乘法 |
| 单bin溢出未明确非负截断 | 使用max(0,真实+静态电荷−容量)，不含filler | 防止正负溢出抵消 |
| filler按目标密度再次缩放可能改变总电荷 | filler电荷密度1，面积按加权剩余容量计算 | 与宏d权重保持总量一致 |
| λ描述“逐渐增加”但MS倍率可小于1 | μ限制[0.75,1.1]，不声称逐轮单调 | GUI曲线如实记录 |
| γ指数排版不清 | 采用10的幂，τ与wb定义明确，稳定截断另记 | 防止误用乘法及溢出 |
| 宏合法化讲义只给概念 | 设计具体SA变量、代价、温度、候选、合法解保存 | 区分论文启发与项目实现选择 |
| Abacus默认等高且宏已合法 | 限定单高度整站点，先宏后标准 | 非支持对象明确拒绝 |
| CImg示例仅硬编码创建一个节点 | 示例不证明解析或全流程可用 | 不将示例当成已有完整工程 |

## 4. 设计决策记录

| 编号 | 决策 | 原因及代价 |
|---|---|---|
| ADR-01 | Linux/C++17/CMake，GUI可选 | 满足课程环境与无桌面测试；Windows不是本版验收平台 |
| ADR-02 | Qt Widgets + Graphics View，纯查看与运行控制 | 适合属性/表格/画布；不引入编辑撤销模型 |
| ADR-03 | 算法核心无Qt，GUI/CLI共享应用服务 | 避免两套算法和状态语义 |
| ADR-04 | 快照只读、容量1预览槽、5Hz节流 | 避免线程共享可变位置与事件积压；完整指标写文件 |
| ADR-05 | 密度采用保守三角核卷积与精确离散能量导数 | 支持一致梯度测试；不同于简单−qE点采样和原作者具体离散实现 |
| ADR-06 | 离散Neumann算子、DCT-II/III | 明确采样点与边界；不能混用连续频率特征值 |
| ADR-07 | 第一版不启用预条件器 | 降低错误梯度/度量风险；不承诺达到ePlace-MS相同性能 |
| ADR-08 | 宏后直接Abacus，不加入第二轮标准单元全局优化 | 满足已确认任务范围；可能牺牲线长，不宣称完整ePlace-MS流程 |
| ADR-09 | SA只平移固定方向，Abacus不自动翻转 | 容易追踪引脚及方向约束；缩小支持空间 |
| ADR-10 | BookShelf无物理比例时用GDS显示映射 | 可以查看几何但不伪造工艺尺寸；输出必须明确标识 |
| ADR-11 | 静态阻挡求并集；宏SA保留独立bestLegal | 避免重复密度和把低代价非法解标成功 |
| ADR-12 | Filler上限20000、尺度自适应Href、γ截断 | 控制教学数据资源并适应单位；全部记录为工程参数 |
| ADR-13 | 后台暂停使用控制令牌与条件变量 | 长循环会阻塞worker事件循环，排队slot不足以保证控制及时性 |
| ADR-14 | GDS采用Limbo写出、KLayout独立回读 | 避免只做文本文件冒充GDS；仍需锁定构建版本 |

## 5. 数据来源和使用限制

BookShelf基准位于 `综合设计III参考资料/任务2参考/BookShelf格式的解析/`。thin1仅有3个可移动标准单元却含890行；adaptec1/4为大规模场景。节点数量包含终端，不能将NumNodes直接当移动单元数。原始 `.pl` 中大量原点位置需要显式initial准备，不能当作合法基准。

本次只检查了现有数据头部与示例结构，不声称所有大型nets条目已通过解析，也不声称LEF/DEF完全配套。开发基线阶段必须执行完整引用和格式审计。
