# 文档维护补充规范

继承根目录 `AGENTS.md`。

- 保持现有中文分册结构；新增开发流程说明放独立文件，并更新根 README 导航。
- 需求、字段、参数、默认值、错误、单位及状态须跨分册一致；改接口必须同步测试追踪。
- 所有类/结构体/元组设计均需字段、类型、含义及单位说明；函数接口设计列明功能、所有输入输出、前后置条件与失败。
- 区分“已实现”“设计”“待执行”“已验证”；未运行软件不能写已通过，官方文档能力不能当本地集成证据。
- 链接以当前文件位置解析；参考资料保持外部只读，迁移文档后核对所有来源路径。
- 文档修改采用 `doc: 中文说明` 提交；子代理只交付修改和核查结果，由主代理统一提交。
