分析、CImg BMP 和 Limbo GDS writer 的适配代码已实现；完整导出/独立回读验收仍按验收追踪区分。Limbo API 以固定提交所附 `GdsParser::GdsWriter` 流接口为依据，不以旧版 GdsDB 文档名称推断本地 API。见[实现与验证记录](12-开发与验证记录.md)。

## 1. 分析基准

所有展示从相同只读 Snapshot 和数据库读取，拒绝坐标与指标来自不同 revision。分析层不修改位置，不从 BMP 或 GUI 像素反推指标。

| 指标 | 定义 | 解释 |
|---|---|---|
| hpwl / weightedHpwl | 各网络真实引脚 bbox 的宽高和，后者乘网络权重 | 不含 filler，不等同实际布线长度 |
| overflow | 任务 5 定义的加权密度溢出率 | 不证明几何合法 |
| overlapArea | 真实矩形对的正面积交集之和 | 多重重叠可重复计入，明确为 pairwise 指标 |
| violationCount | 独立检查器按类型的记录数 | 记录截断不影响完整计数 |
| mean/max/L1 displacement | 与指定参考阶段的单元中心位移 | 宏、标准单元分开统计；固定对象单列 |
| quadratic displacement | Σ[(x−xref)²+(y−yref)²] | Abacus 优化量，不与欧氏位移均值混用 |
| elapsed / peak memory | 单调时钟耗时、进程峰值内存 | 标注是否含加载/导出及运行环境 |

位移基准：global 对 initial；macro_legal 对 global；standard_legal 对 macro_legal，同时补报最终对 global。HPWL 改善率=(Hinitial−Hstage)/Hinitial，Hinitial=0 时为 null。宏、标准单元、固定端口、可移动数量和网络度数分布同样进入报告。

## 2. 共享几何和配色

CoreRegion 为行并集 bbox；ChipRegion 为 core 与所有终端几何的 bbox。显示 chip，但允许“仅 core”视图。零面积顶层端口以符号标识，不伪造成有面积实例。无有效几何时使用占位视图并显示“无可显示区域”。

| 对象 | 默认颜色（十六进制） | 图层 |
|---|---|---|
| 背景 | #FFFFFF | 最底层 |
| core / chip 边界 | #334155 / #64748B | 边界 |
| 标准单元 | #DC4C4C | 实体 |
| 可移动宏 | #239B56 | 实体 |
| 固定实体/终端 | #475569 | 实体与固定标识 |
| 行 | #CBD5E1 | 辅助线 |
| 选中对象/网络 | #2563EB / #EAB308 | 覆盖层 |

GUI 可开关图层，离线图像使用相同颜色与图例。固定宏为宏几何并附固定标识，不同时输出两个重叠实体。显示状态不改变数值分析。

## 3. CImg 无窗口绘图

默认图像有效宽 W=1600，边距 m=24；chip 尺寸 Lx、Ly 均须>0，比例 s=min(W/Lx,8192/Ly)，有效高 H=ceil(sLy)。若高度上限约束使有效宽变小，记录实际尺寸；每方向总尺寸含 2m，不得因取整引入不同 x/y 比例。

数学点映射为 px=m+s(x−chip.llx)，py=m+s(chip.ury−y)。矩形屏幕左上角由 (llx,ury) 映射，右下角由 (urx,lly) 映射；再做像素裁剪。禁止先翻转节点坐标又对图像整体再翻转。像素索引范围是 0 到 size−1，最右/最下边界必须裁剪。

绘制顺序：背景 → 行/可选 bin → 端口与实体 → 边界 → 选中/违规（若指定）→ 标题与图例。小于一像素的实体可显示一像素标记，图例注明该标记仅为可见性近似，不能据此判断重叠。零面积端口用十字。

使用 CImg 保存 BMP，不要求打开窗口；中文长标题在外部报告表达，图内使用简短 ASCII 标识、数值和颜色图例，避免默认字体缺字。输出文件标识 stage/revision、DU 或 μm、运行终止及合法性摘要。BMP 本身不承载完整元数据，manifest 记录来源。

## 4. GDSII 导出契约

通过 Limbo GDS 数据模型和 `GdsParser::GdsWriter` 流 writer 适配，提供稳定 ExportSnapshot 接口。导出的是布局矩形/参考线，不是完整工艺版图或可流片文件。

### 4.1 单位与精度

user unit 定义为 1 μm，默认 DBU 为 0.001 μm。物理坐标 xum=xDU×microns_per_du；无物理比例 BookShelf 使用显式显示映射 1 DU=1 μm，界面在首次导出前显示该映射，用户可调整并保存。GDS UNITS 按 writer 的语义分别设置 DBU/user-unit 和 DBU/metre，不把两个字段都填 0.001。

量化 q=round(xum/DBU)，采用最近整数、正负中点远离零；每轴误差≤DBU/2。临时用 int64 检查后转 GDS 有符号 int32，溢出则报错并建议增大 DBU。相同输入坐标始终同样量化。宽高量化后坍缩为零的非零实体返回精度不足错误，不能静默丢弃。

几何合法性以未量化快照为准；量化后重新检查并报告是否新增接触或重叠，不将两种结果混为一谈。面积相交可因量化变化，需在报告标明 DBU 和误差。

### 4.2 图层与结构

| layer/datatype | 内容 | 默认 |
|---|---|---|
| 1/0 | 标准单元矩形 | 输出 |
| 2/0 | 可移动宏矩形 | 输出 |
| 3/0 | 输入固定实体矩形、端口标记 | 输出 |
| 10/0 | core 边界及可用行轮廓 | 输出 |
| 11/0 | chip 边界 | 输出 |
| 20/0 | 违规区域或对象轮廓 | 有违规时输出 |
| 30/0 | 被选网络的示意线 | 可选，非真实布线 |

一个顶层结构使用安全 ASCII 名称，例如 PLACEMENT_GLOBAL，长名称与对象名保存在伴随 JSON，避免字符编码和 GDS 名称限制。矩形使用闭合的五点 BOUNDARY；边框和示意网络使用 PATH，线宽显式为至少 1 DBU。默认不为每个单元输出文本、不输出 filler、不展开全部网络，避免文件膨胀。实体 layer 互斥，固定宏只在 layer 3 输出，分类可从伴随数据恢复。

### 4.3 写出与复核

导出先验证单位、范围和对象数量，再写临时文件，关闭并检查后原子重命名；metadata 含源 snapshot、物理比例已知标志、DBU、各层数量和量化最大误差。失败删除本次临时文件，不覆盖已有成功文件。

KLayout 复核步骤：打开 GDS → 检查顶层结构和 DBU → Fit All → 查看各层 → 抽查 core 尺寸、一个标准单元、一个宏、一个固定对象 → 对照坐标标尺与报告。自动集成验证以独立 KLayout 批处理读取和导出几何清单为准；本次仅描述流程，不提供脚本。

## 5. GUI 与阶段比较

GUI 实时画布由 Qt 渲染，不每帧先生成 BMP 再加载。仅“保存画布截图”包含当前图层与视口；“导出标准布局图”由 CImg 对整个 chip 生成，两者分别标注用途。

阶段比较要求 datasetId 一致，左侧默认 initial、右侧默认最新完成阶段。相机同步使用数学坐标下的视口中心和 DU/像素比例，不直接复制两个窗口不同尺寸的像素变换。指标表包含绝对值、差值和改善率，不以颜色暗示所有指标均越小越好。

## 6. 验收规则

人工几何小例核对四角映射和 Y 方向，允许离线像素取整误差≤1 px；GDS 回读坐标误差≤DBU/2（若比较量化前值），实体类别、数量和 bbox 与 manifest 一致。GUI 选中对象属性展示原始 DU 坐标，任何舍入仅影响显示。

全局、宏合法和最终快照分别导出，检查文件和阶段身份对应。损坏路径、无权限、目标存在、磁盘写失败、导出取消等均需测试。通过截图相似度不足以证明几何正确，必须同时核对坐标和对象清单。
