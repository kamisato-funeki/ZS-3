# 任务 7：布局检查与合法化详细设计

版本：1.0。导航：[首页](../README.md) · [接口](04-总体技术与接口设计.md) · [测试](09-测试用例与验收方案.md)。关联需求：REQ-LG-01～04。

## 1. 阶段目标与支持边界

宏合法化以消除宏/宏、宏/固定障碍重叠并约束边界为主要目标，兼顾线长和位移；标准单元合法化在宏固定后，最小化位移并满足行、站点和无重叠约束。

采用流程：删除 filler → 独立检查 → 宏 SA → 宏检查 → 行切分 → Abacus → 完整检查。全局布局与合法化目标不同，合法化后 HPWL 允许上升，但必须量化记录。

支持轴对齐矩形宏、固定方向、水平等高标准单元及整站点宽度。宏在 core 内且其 footprint 不穿越硬阻挡/非可放置区域；标准单元在单个行区间内。输入固定终端可在 core 外，不按标准单元行约束检查。旋转搜索、多高度单元、非矩形区域和跨行单元不在本版修复范围。

## 2. 独立合法性检查器

检查器不复用 SA 的“成功标志”或 Abacus 的临时簇作为真值。使用最终位置重新建立空间索引并核对几何，能够检查任意外部结果。

| 类型 | 判定 | 报告 |
|---|---|---|
| NON_FINITE | 位置、尺寸存在非有限数 | 对象和字段 |
| FIXED_CHANGED | 输入固定对象位置/方向不同于基线 | 原/现坐标及方向 |
| OUT_OF_BOUNDS | 可移动对象不完全位于允许区域 | 超出边界及面积 |
| OVERLAP | 两个有面积实体的交集宽、高均超过 εg | 两个 ID、交集、面积 |
| HARD_BLOCKAGE | 实体与硬阻挡正面积相交 | 对象与障碍来源 |
| OFF_ROW | 标准单元 lly 与合法行 y 不匹配或高度不匹配 | 最近行与差值 |
| OFF_SITE | (llx−rowOrigin)/pitch 非整数，误差超过 εs | 最近站点及偏差 |
| ROW_CAPACITY | 区间占用跨度超过容量 | 行区间、需求与可用站点 |
| ORIENTATION | 对象方向不符合行/站点及 master 对称性 | 原方向与允许集合 |
| UNSUPPORTED_OBJECT | 多高度、非整站点宽度等 | 明确原因 |

固定对象之间已有相交作为输入几何冲突报告，不允许移动固定对象“修复”。零面积端口不参与面积碰撞；边界接触不算重叠。普通检查输出全部违规计数，详细记录最多 10000；排序按类型、最小 NodeId、最大 NodeId，保证可重现。

采用 x 轴扫描线与活动区间结构，复杂度 O((N+K)log N)，K 为实际相交对数量；密集重叠可导致 K 近二次，不承诺线性时间。GUI 显示记录截断标记，不能把“未列出全部”视为检查通过。

## 3. 宏单元模拟退火

### 3.1 变量与代价

仅调整 movable macro 的左下角，标准单元坐标暂时保持 global 状态；fixed/terminal 不动。禁止修改输入方向。没有 movable macro 时跳过搜索，仍执行宏范围检查，成功提交相同几何的 macro_legal 阶段。

代价采用归一化量：C=α·H/Href+β·Dmacro/Dref+η·O/Oref，其中 H 为加权真实 HPWL，Dmacro=Σ宏中心到 global 位置的平方位移，O 为宏之间及宏与静态不可放置区的相交面积和。默认 α=1、β=0.1；Href=max(Hglobal,1 DU)，Dref=max(Nmacro×hrow²,1 DU²)，Oref=max(宏总面积,1 DU²)。

η 初始 10，每 10 个 sweep 未达到零重叠则乘 2，上限 10⁶。宏候选始终限制在 core bbox；非行区域与固定障碍以 O 表达。标准单元暂时重叠不加入硬合法约束，因其将在下一阶段移动，但其引脚参与 H。

代价用于搜索排序，最终可行性由检查器给出。O 较小不等同为零违规；代价下降也不等同找到合法解。

### 3.2 候选、温度与接受

默认 100 sweep，每个 sweep 对每个宏尝试 20 次移动，以固定种子打乱宏顺序。80% 候选为当前位置周围随机平移，20% 候选在可放置区域随机重定位；初始移动半径 r₀=0.1×max(Lx,Ly)，后期降到 rmin=hrow，r(s)=max(rmin,r₀×(1−s/100))。位置投影到 core bbox 后若无变化则重采样，最多 10 次。

使用最多 100 个可计算候选估计正代价增量中位数 m，T₀=−m/ln(0.8)，无正增量时 T₀=max(0.01,0.01|Cinitial|)。Tmin=10⁻⁴T₀，每 sweep 温度按几何序列下降至 Tmin。更新 η 后以当前权重重新计算当前与候选 C，不用旧权重的缓存代价比较。

ΔC≤0 接受；否则以 exp(−ΔC/T) 接受，使用 log(U)<−ΔC/T 避免数值下溢。增量更新受影响网络和空间索引，拒绝移动必须恢复坐标、索引和缓存。每个 sweep 全量核对一次代价，排查增量漂移。

同时维护 `bestCandidate` 与 `bestLegal`：前者便于诊断，后者仅在宏独立检查通过后更新，按 H+位移代价选择。若初始宏已合法，直接保留其结果，不为了降线长额外扰动。搜索预算结束，有 bestLegal 就提交；没有则返回 NO_LEGAL_SOLUTION_FOUND，不把“未找到”写成数学不可行证明。

### 3.3 几何预检与失败

宏宽/高超过可允许区域、固定障碍已构成不可修复冲突、总必要面积不满足时可报告明确不可行证据。一般组合可行性不作未经证明的判定。失败结果不创建 macro_legal 成功阶段，只保留 global 与诊断候选，标准合法化不自动继续。

取消在每次移动、候选计算批次和 sweep 边界检查；暂停在完成一次候选提交/回滚后生效。未完成的候选不形成预览快照。

## 4. 标准单元可用行切分

对每个原始 row/subrow，收集与其 y 跨度有正面积相交的固定实体、硬阻挡与已合法宏。将障碍 x 投影合并为并区间，再从原始可用行区间扣除。跨多行宏必须切分每一条相交行。

行区间统一表示为 `[L,R]` 的物理可容纳跨度，起始 L 向右对齐站点，结束 R 向左对齐站点；取 ceil/floor 时只用 εs 消除浮点边界噪声，禁止将实际重叠吸收掉。以 rowOrigin 为全局站点基准，不能把每个障碍末端当作新的任意网格原点。

站点间距须等于站点宽度，标准单元宽度为其整数倍。每个区间保存 rowId、origin、y、height、orientation、startSite/endSite、capacity。零容量区间丢弃，区间相互不重叠。标准单元方向保持输入方向，候选行须允许该方向；不自动翻转以适应行。

预检每个标准单元至少有一个尺寸及方向兼容区间，总可用站点面积≥标准单元面积。不满足时给容量/兼容性证据；满足仍可能因逐个分配失败而“未找到解”。

## 5. Abacus 标准单元合法化

### 5.1 目标与顺序

参考目标点为 macro_legal 中标准单元的左下角 (xᵢ⁰,yᵢ⁰)，默认权重 eᵢ=1。优化 Σeᵢ[(xᵢ−xᵢ⁰)²+(yᵢ−yᵢ⁰)²]，约束同一区间内按参考 x 顺序不重叠、落在合法站点、区间内及匹配行高/方向。

按 (xᵢ⁰,NodeId) 稳定排序后逐个处理，候选区间按 (|rowY−yᵢ⁰|,rowId,startSite) 排序。默认遍历所有候选，用新增单元垂直位移成本作为下界剪枝；它是该单元加入后目标增量的下界，因为原有行解在相同顺序下已最优。仅当前最佳代价严格更小时才剪枝，同分保持稳定规则。

### 5.2 行内簇

将坐标转换为站点坐标 t=(x−rowOrigin)/pitch，宽度 w 为整数站点数。一个簇中各单元紧靠排列，簇保存总权重 E、总宽 W 和 Q=Σeᵢ(tᵢ⁰−offsetᵢ)。连续最优起点 t*=Q/E，约束到 [startSite,endSite−W] 后，选择最近整数（等距取较小整数）。整数宽度保证簇内所有起点仍对齐站点。

加入新单元到簇末尾：Qnew=Q+e(t⁰−W)，Enew=E+e，Wnew=W+w；随后重算起点。若与前簇相交则向左合并。合并左 A 与右 B：E=EA+EB，W=WA+WB，Q=QA+QB−EB·WA，再约束和取整起点；重复直到与更前簇不重叠。

从簇起点累加整数宽度恢复每个单元位置。容量不够的区间在试放前拒绝；不得通过把最后单元钳到右边界制造重叠。该方案是单高度、同站点宽度约束下的 Abacus 簇实现；使用整数簇起点后仍须小规模枚举核对目标最优性，不把所有多行分配宣称为全局最优。

### 5.3 候选试放与提交

对候选区间复制受影响簇或建立可撤销日志，插入单元后执行 PlaceRow。候选代价为该区间新旧总二次位移之差加新单元垂直项，不能只比较新单元自己的位移，因为已有单元也可能被移动。其余行不变。

选择最小增量，等代价按 rowId、startSite 决定；提交最佳试放，所有其他试放完整回滚。没有可行区间时返回 NO_LEGAL_SOLUTION_FOUND，并列出单元、兼容区间及剩余容量，不发布部分合法布局为成功结果。本版不做随机重试、跨区间交换或隐式算法切换。

## 6. 结果提交与最终检查

宏阶段成功先发布 macro_legal；标准阶段仅在所有单元放置并完整检查通过后发布 standard_legal。固定对象和宏位置与阶段基线逐项核对。若输入快照已经完全合法，直接保留坐标并发布完成结果，保证再次合法化幂等。

最终报告分别记录初始/最终违规、各阶段位移、线长变化、搜索预算、种子、容量摘要和终止原因。检查器非零违规时为失败，即使内部算法声称完成也不能覆盖最终合法性结论。

## 7. 手算示例与性能

行 [0,10]、站点 1，单元 A/B 宽度均 3，参考 x 为 1、2。合簇 E=2、W=6、Q=1+(2−3)=0，起点 0，位置 A=0、B=3，总水平二次位移 1+1=2，无重叠。将 B 单独推到 4 得成本 4，说明簇重排的作用。

若障碍占 [4,6]，切分为 [0,4] 和 [6,10]；宽 5 的单元无法放入任一区间，尽管总空白长度为 8，仍应失败。候选容量不能只看总面积。

宏 SA 的主要成本为移动次数×受影响网络/碰撞查询；Abacus 排序 O(NlogN)，全部候选行试放最坏可较高，不能笼统承诺全程线性。性能实验记录候选数、簇合并数、试放回滚成本及最大区间规模；优化前保留穷举候选模式作为正确性基线。
