# 交互 GUI 详细设计

版本：1.0。导航：[首页](../README.md) · [接口](04-总体技术与接口设计.md) · [测试](09-测试用例与验收方案.md)。关联需求：REQ-UI-01～06、REQ-NF-03～04。

## 1. 方案与层次

采用 Qt 6 Widgets，主窗口为 QMainWindow，可停靠面板使用 QDockWidget，表格/树使用模型视图，中央使用 QGraphicsView/QGraphicsScene。收敛曲线用 QWidget/QPainter 绘制，避免额外引入 Qt Charts。算法服务独立于 Qt，GUI 只负责把用户操作转成请求、把事件转成界面状态。

Qt Graphics View 提供场景、视图和坐标变换，参见[官方框架说明](https://doc.qt.io/qt-6/graphicsview.html)。本项目的大数据策略仍需自行设计和测量，不根据框架说明推定半百万实例必然流畅。

## 2. 主窗口静态原型

```text
┌ 文件  运行  视图  导出  帮助 ─────────────────────────────────────┐
│ 打开 │ 参数 │ 启动 ▼ │ 暂停 │ 继续 │ 取消 │ 适应 │ 对比 │ 导出 │
├──────────────┬───────────────────────────────┬───────────────────┤
│ 项目与数据    │ 布局画布 / 双视图               │ 属性 / 违规        │
│ 输入路径      │ [initial ▼] [global ▼]        │ 对象 ID / 名称     │
│ 单位、统计    │                               │ 坐标、尺寸、方向    │
│ 阶段树        │   平移、缩放、选择、网络高亮      │ 网络列表            │
│ 图层开关      │   热力图、bin、行和违规标记       │ 违规筛选与定位      │
│ 参数分组      │                               │                   │
├──────────────┴───────────────────────────────┴───────────────────┤
│ 指标：迭代 / HPWL / overflow / 位移 / 耗时 / 状态                 │
│ [收敛曲线] [运行日志] [加载诊断]                                   │
├─────────────────────────────────────────────────────────────────┤
│ 状态栏：任务阶段、坐标、缩放、DU/μm、选中数、快照 revision           │
└─────────────────────────────────────────────────────────────────┘
```

默认窗口建议 1440×900，最小 1024×720；低分辨率下停靠面板可折叠，画布优先保留空间。首次启动为空项目，中央提示选择 AUX 或 LEF/DEF；没有数据时禁止启动和结果导出。

## 3. 控件与交互契约

| 区域 | 控件/操作 | 默认与行为 |
|---|---|---|
| 文件 | 打开 BookShelf、打开 LEF/DEF、加载结果 | AUX 自动找关联文件；LEF 可多选、DEF 单选；结果需原输入指纹匹配 |
| 参数 | 初始、全局、宏、标准、显示/导出分组 | 默认值来自有效配置；算法与显示参数明确区分 |
| 启动 | 全局 / 宏 / 标准 / 全流程 | 默认全流程；宏需 global，标准需 macro_legal；缺少前置阶段显示原因 |
| 控制 | 暂停、继续、取消 | 分别只在对应状态可用；重复点击无副作用 |
| 阶段树 | initial/global/macro_legal/standard_legal | 仅完成阶段可选；失败候选放诊断区而非成功树 |
| 图层 | 标准、宏、固定、行、bin、热力图、违规 | 实体/边界默认开；行/bin/热力图默认关；违规有结果时默认开 |
| 名称查找 | 精确/前缀查找、候选列表 | 默认精确，区分大小写；大列表分页，Enter 定位 |
| 属性 | ID、名称、kind、ll、center、尺寸、方向、固定性、网络 | 只读；数值展示精度可调，复制使用原精度 |
| 网络 | 选择所属网络、隐藏高亮 | 默认只展开所选对象网络；不常驻全部网络图元 |
| 违规 | 类型过滤、严重度、计数、双击定位 | 双击拟合违规 bbox 并选中对象；截断时显示总计/已列出数 |
| 曲线 | HPWL/overflow 切换、悬停、阶段标记 | 默认双轴分图，避免把单位不同的量画成同轴 |
| 日志 | 级别、文本过滤、复制、打开保存位置 | 默认 Info 及以上，内存保留最新 5000 条 |
| 导出 | 标准布局 BMP、GDS、placement JSON、报告、画布截图 | 明确阶段与单位；不允许把当前视口截图当完整布局图 |

导入为事务：加载中旧项目仍可浏览，禁止启动旧项目计算；新项目加载/审计失败时保持旧项目，展示路径、对象和错误原因。加载成功才替换 datasetId、清理选择与旧事件，生成 initial；若自动位置准备发生调整，加载摘要醒目标明对象数量和规则。

输入校验同时检查范围、有限数和跨字段关系。例如 target_density=0、preview_hz=0、grid=30、DBU≤0 拒绝提交；容量可行性需要后台预检，启动后失败返回具体面积，而非无响应。

## 4. 画布行为

- 滚轮以鼠标所在数学坐标为缩放锚点，每档倍率 1.2；比例范围为 Fit 比例的 10⁻³～10³。
- 中键拖动或空格+左键平移；左键单击选择、Ctrl+单击增减选择、空白单击清空；拖框选择仅选择可见图层实体。
- F 适应 chip，Shift+F 适应 core，Esc 清空选择/高亮；Ctrl+O 打开，Ctrl+E 导出。所有快捷键在菜单可发现。
- 重叠对象单击按顶层优先，再按面积小者和 ID 排序；Alt+单击循环候选，避免大宏完全遮住小对象。
- 拖动物体只产生选中，不修改位置；图元不可移动。属性面板不提供写入口。
- 双击违规记录以 bbox 为中心并额外留 10% 边距，状态栏显示违规类型和数值。被隐藏图层相关对象临时显示高亮轮廓，不修改原图层开关。
- 网络高亮采用“网络引脚到平均中心”的示意星形线，明确非布线。大网络默认最多画 5000 个确定性抽样引脚并显示抽样提示，HPWL 仍使用全部引脚。

场景坐标直接使用 (xDU,−yDU)，不在 view 再做 Y 轴翻转。节点框由 (llx,−ury,width,height) 构造，鼠标场景点 (sx,sy) 映射回 (sx,−sy)。文字使用不随视图缩放/翻转的覆盖层，图例放 viewport 上；CImg 采用自己的屏幕映射，不复制 Qt 的负号到领域坐标。

## 5. 运行状态与允许操作

主运行状态与导出任务状态分离。主状态增加 `loading`，阶段字段区分 prepare/global/macro/standard/check；进度不能确定时显示忙碌标识，不伪造总完成百分比。

| 主状态 | 打开/替换输入 | 修改算法参数 | 启动 | 暂停/继续 | 取消 | 查看/导出已有快照 |
|---|---|---|---|---|---|---|
| empty | 允许 | 允许 | 禁止 | 禁止 | 禁止 | 无可用结果 |
| loading | 禁止重复打开 | 禁止 | 禁止 | 不支持 | 允许 | 旧项目允许 |
| ready | 允许 | 允许 | 允许 | 禁止 | 禁止 | 允许 |
| running | 需先取消结束 | 禁止 | 禁止 | 算法阶段可暂停 | 允许 | 允许 |
| pausing | 禁止 | 禁止 | 禁止 | 等待安全点 | 允许 | 允许 |
| paused | 需先取消结束 | 禁止 | 禁止 | 可继续 | 允许 | 允许 |
| cancelling | 禁止 | 禁止 | 禁止 | 禁止 | 幂等 | 允许 |
| completed/cancelled/failed | 允许 | 允许 | 数据有效时允许 | 禁止 | 禁止 | 允许 |

终态若无有效数据，行为按 empty。修改参数令当前配置标为“未运行”，已有快照仍附原配置，不重新标记成新参数结果。失败不自动重新执行；用户点击重新运行才创建新 runId。

主要转移：ready→running；running→pausing→paused→running；running/pausing/paused→cancelling→cancelled；running→completed 或 failed。取消优先于暂停。阶段切换也经过安全点；用户已请求暂停时不在后台偷偷开始下一阶段。

解析与导出只支持取消。大型检查显示忙碌阶段，暂停在检查后生效；FFTW 单次执行不可抢占。界面文字显示“正在等待安全点”，不能点击暂停后立即声称已停止计算。

## 6. 后台执行与生命周期

### 6.1 职责分离

主线程拥有窗口、场景、Qt models、QTimer、QPixmap；工作线程拥有 worker QObject 和算法任务缓冲。只读数据库跨线程共享，运行位置不可由主线程直接访问。后台可以构建纯 C++ 的几何分块/空间索引包，QGraphicsItem 的创建和更新仍在主线程。

worker 使用 moveToThread 模式，QThread 对象本身由主线程拥有。worker 与主线程通过显式排队连接通信。该规则依据 [Threads and QObjects](https://doc.qt.io/qt-6/threads-qobject.html)，第三方回调内不得访问 QWidget。

### 6.2 暂停与取消

核心循环可能长时间占据 worker 事件循环，因此不能只往 worker 投递 pause/cancel slot。GUI 经线程安全的普通 C++ ControlToken 设置原子标志；取消同时清除暂停等待条件并 notify_all。算法到达完整提交/回滚安全点后才进入等待，锁内再次检查取消，避免丢失唤醒。

安全点：全局布局完整接受迭代后；SA 完整候选处理后；Abacus 一个单元提交后。网络与密度计算每 4096 个对象/引脚检查取消；解析每 4096 行、导出每 4096 个实体检查取消。不能在半提交的数据上暂停并发布快照。

关闭窗口时弹出明确选项：“取消任务并关闭”或“返回”。确认后进入 closing 流程，禁用新操作、设置取消并保持事件循环工作；收到 worker finished 后退出线程、释放 worker，再销毁窗口。不得在主线程长时间 wait 卡住界面，不使用 QThread::terminate，也不让仍运行的线程被析构。

### 6.3 事件身份

每个事件带 datasetId、runId、stage、iteration、revision、sequence；导出事件另带 exportId 和源 snapshotId。主线程先验身份再更新界面。被替换项目和上一次运行的迟到进度、错误及 finished 都不能覆盖当前状态。每次运行只有一个终态，取消与正常完成竞争由应用层原子终态提交决定。

## 7. 快照、曲线和日志的有界传递

核心每轮计算完整指标并写流式 metrics；GUI 不逐轮接收完整坐标。工作线程维护容量 1 的最新预览槽，主线程 200 ms 定时取走；新预览覆盖未显示旧预览。已显示与待显示预览合计至多 2 份，另允许工作线程构建 1 份临时缓冲。拓扑共享不复制。

完成阶段快照独立保存，四阶段至多 4 份；相同快照共享引用。导出只允许一个活动导出任务，固定持有一份源快照，必须计入峰值内存。完成/失败/取消信号不经过预览覆盖槽，主线程处理终态前安装最终完整快照，完成时即使定时器尚未触发也必须显示结果。

快照构建按 preview_hz 节流，不能每轮复制全量坐标后再丢弃。scene 采用整份 render packet 切换，分块更新均绑定同一个 revision，选中属性与密度热图随同切换，不出现新坐标配旧热图。若当前导出源与画布不同，在导出对话框显示其阶段及 revision。

曲线保留最多 5000 个显示点，超过后按时间桶保留极值并合并旧桶，最终点始终保留；完整指标保存在 CSV。日志内存环形缓冲 5000 条，完整日志异步写 events.jsonl；高频 DEBUG 消息可聚合但必须显示丢弃计数，错误和终态不可丢。

## 8. 大规模场景渲染

默认以 core 的 64×64 空间块组织实体索引，每个块一个批量绘制图元；跨块对象由中心所属块绘制，块 boundingRect 扩展到其实体 bbox，另有统一命中索引避免遗漏。超大宏单独图元管理。不可为近两百万引脚预创建 Item。

LOD 依据投影尺寸：对象小于 1 px 时绘制聚合密度或点；1～8 px 时批量矩形不画文字；大于 8 px 显示轮廓；名称只对选中或查找对象显示。视口裁剪排除不相交块，局部刷新只更新受影响块。密度热图为有界 nx×ny 网格，颜色范围绑定 target_density 并给色标，不按每帧极值自动改色造成误读。

选择命中采用 NodeId 空间索引精确查矩形；视图像素仅用于容差，不改变数学命中规则。帧耗时超预算连续 10 次时自动进入粗 LOD，并显示提示，用户可恢复精细显示；指标计算和导出不使用粗几何。

## 9. 阶段对比与导出流程

进入对比默认左 initial、右最新完成阶段，若仅 initial 则提示需更多阶段。两份场景共享拓扑但持有独立位置与索引。同步导航传递数学中心和 DU/px 比例，用重入标志避免左右信号循环；选择同步通过 NodeId，网络与违规按各自阶段计算。

导出流程：选择快照 → 选择格式/路径 → 查看单位/状态摘要 → 校验 → 后台写临时文件 → 原子提交 → 显示路径与结果。正在运行或暂停时可以导出已完成快照或最后完整预览；预览文件含 `preview`、iteration 和非最终标记。导出失败只影响 exportId，不改变算法运行状态。导出取消只取消导出，主算法继续原状态。

GUI 输出的 GDS 不是必须内嵌 KLayout 才能查看；提供路径复制与使用 KLayout 打开的操作说明。未安装 KLayout 只影响外部查看，不阻止 GDS 导出与 GUI 本身使用。

## 10. GUI 验收

Qt Test 覆盖输入校验、状态转移、按钮使能、场景坐标、命中、视图同步和假 worker 事件；核心控制令牌用确定性屏障测试取消唤醒，避免靠任意 sleep 判断。显示测试可在 offscreen 平台执行，真实窗口缩放、字体和桌面关闭仍需手工复核。

在 adaptec1/adaptec4 测量首次可交互时间、平移/缩放 P50/P95、选中查询、帧耗时、快照数和峰值内存；记录硬件、Qt/驱动、视口大小及 LOD。100 ms 操作反馈和 200 ms 视图响应 P95 是待验证目标；未达标必须记录、优化或经需求变更处理，不能填作已满足。
