## 实现范围

| 模块 | 实际入口 | 实现内容 |
|---|---|---|
| 领域模型 | `include/placement/core/model.hpp`、`src/core` | 稳定ID、八方向、物理容差、单位、只读拓扑/快照、固定性及协作令牌 |
| 输入 | `src/io/bookshelf`、`src/io/lefdef` | 六文件关联、权重/引用审计、SHA-256、Limbo所附LEF/DEF 5.8解析器适配 |
| 全局布局 | `src/global` | 精确WA梯度、守恒平滑密度、静态并集、filler、FFTW正交DCT、离散泊松、投影Nesterov |
| 合法化 | `src/legalization` | 保持方向的宏SA、行障碍切分、整站点Abacus、独立复检后发布 |
| 分析/导出 | `src/analysis`、`src/visualization` | 真实HPWL与分类位移、完整违规计数、有界详情、CImg BMP、真实GDSII及量化审计 |
| 应用/CLI | `src/application`、`src/cli` | 配置优先级、独占运行、四阶段快照、事件/指标流、原子提交、重载及明确退出码 |
| GUI | `src/gui` | Qt Widgets、后台任务、安全点暂停取消、容量1预览、阶段比较、分块/LOD、命中、属性和独立导出 |

公共接口不暴露 Qt、FFTW、Limbo、CImg 类型。真实实例与任务私有 filler 分离；GUI 热图明确为真实与静态电荷之和，不含未存入快照的 filler。

已按实施契约统一几何距离容差和 DU 站点残差。碰撞与边界采用 `min(εg, 10⁻⁶ pmin)`，无行时用 εg；面积仍统计真实交集。行切分保留原始网格。初始 overflow 达标可直接完成，否则连续五轮达标才收敛；配置中的 `convergence_window` 固定为5。达到迭代上限的结论会跨后续合法化保留。

LEF/DEF 原点有一项文档勘误：DEF 位置对齐方向后 SIZE 框左下角，LEF ORIGIN 先作用于引脚几何；见[04分册](04-总体技术与接口设计.md)。八方向和非零 ORIGIN 已用独立世界坐标真值验证。

## 2026-11-02：Qt快照指标、缺失曲线与首次双视图显示修复

### 实际根因与范围

- `install()` 原先更新底部指标和项目摘要，`chooseStage()` 只换包并更新部分检查项，导致画布与状态栏不属同一快照。现在安装、阶段选择、单双切换和选择侧共用 `refreshSnapshotUi()`；单视图取实际左包，双视图逐侧标明身份及同轮指标，摘要也逐侧展示冻结准备配置与调整数。属性、违规类型过滤及定位显式绑定检查侧；共用快照也不混淆定位目标，选择引发列表重建前复制定位记录。
- 两条曲线的 `value_or(0)` 将缺失变成零，且持续 `lineTo`，单点还直接跳过。现在只有有限有效值参与范围与绘图，缺失断段，后续开启新段，零与单点有标记，提示缺失显示“—”。旧时间桶压缩同样排除缺失极值，用仅GUI的双单位 `breakBefore` 保留被丢弃缺失区间，并保留正式阶段首次出现点；Snapshot及完整CSV的指标不变。
- 首次展开右面板时，viewport可能仍为零尺寸，`fit()` 得到零比例；后续 `setCamera()` 被零 `fitScale_` 限制，形成不可逆变换，QGraphicsView背景和实体都无法绘制，而屏幕文字覆盖层仍可绘制。修复前新增实体像素回归实际失败，右侧有1个批量图元但相机DU/px为 `1e20`。现在fit/被动相机在正常show/resize有效尺寸时只安装一次，保存左侧已有导航，被动安装不发同步信号。场景及图元仍各归各Canvas，不复制左侧图像。
- 将教学GUI产物隔离到临时目录后，较快写出复现了终态可靠重装与消费交错的乱序批次：全流程已完成却最后显示initial。受控 `global → standard_legal → initial` 批次测试在修复前失败；GUI现按公开阶段顺序安装至多四个包。该调整属于GUI显示提交，不修改应用流水线或算法。
- 改动限于 `src/gui/`、两个新增Qt测试文件及本册、docs/08、09、13；输入、算法、应用服务、持久化schema和依赖均未修改。开始时仓库无未提交改动。
