# 项目任务书

版本：1.0；日期：2026-10-26。导航：[首页](../README.md) · [需求](02-需求规格说明书.md) · [验收](09-测试用例与验收方案.md)。

## 1. 项目名称与背景

项目名称：基于静电模型的集成电路布局与交互分析系统。

布局决定电路单元在芯片可放置区域中的位置。线长短通常有利于后续实现，但只最小化线长会导致单元聚集；全局布局需同时控制区域密度。全局优化得到的连续位置仍可能重叠或不对齐站点，必须进一步合法化。项目通过算法、量化指标、图像和交互界面构成可复核的教学实验流程。

## 2. 任务依据与边界

以本地《工业软件创新训练III-任务描述2026》及任务 5～7 的说明为直接要求，ePlace、ePlace-MS 和 Abacus 论文为算法依据，详见[参考资料](10-参考资料与设计决策.md)。任务 6 的 CImg 绘图与 GDSII/KLayout 两条展示路径均必须保留，GUI 是补充能力。

原任务 7 为选做；经本项目范围确认，宏单元与标准单元合法化均纳入设计和未来验收。任务 1～4 仅作为环境、解析和初始布局的前置能力，不要求在本次重新完成其全部教学内容。

此次实际成果是清单中的 11 份 Markdown 文档（README 加 10 个分册）。未来软件、数据样例、实验记录和测试报告是文档中定义的后续成果，不在本次生成。

## 3. 建设目标

1. 从 BookShelf 或支持子集内的 LEF/DEF 建立统一布局数据库，明确前置数据如何进入任务 5。
2. 采用平滑线长、静电密度和 Nesterov 方法联合优化可移动单元，记录真实 HPWL 与密度溢出率。
3. 用 CImg 输出布局图像，用 GDSII 表达布局几何，并在 KLayout 中复核。
4. 独立检查布局约束，分别处理宏单元重叠和标准单元行、站点对齐问题。
5. 使用 Qt 6 提供参数设置、后台运行控制、交互浏览、违规定位和阶段对比。
6. 为数值正确性、几何合法性、线程安全和大规模查看提供可执行的测试设计。

## 5. 阶段安排与依赖

- 阶段 A：确认文档与数据契约，形成 WP-0/1。核心输入是后续算法与 GUI 的共同基础。
- 阶段 B：先做独立指标与数值模块，再贯通 WP-2；保存初始和全局布局阶段快照。
- 阶段 C：以同一快照贯通 WP-3；独立检查器先于 WP-4 修复算法完成。
- 阶段 D：宏合法化成功后锁定宏位置，执行标准单元合法化；失败时停止成功路径并输出诊断。
- 阶段 E：GUI 接入应用服务，而非重新实现算法。最后执行 WP-6。

不虚构日期、人员及人日。阶段转换以可审核成果和测试证据为准；后续开发者按课程期限分配实际工期。

## 6. 技术与质量约束

C++17、Linux、CMake 为基础。算法核心使用标准库类型及 RAII 管理资源，不持有 Qt 控件。数值变换使用 FFTW3，离线绘图使用 CImg，LEF/DEF 与 GDSII 使用 Limbo 适配层。GUI 使用 Qt 6 Widgets，单元及界面测试分别使用 GoogleTest 和 Qt Test。

数值及拓扑正确性先于优化效果。达到迭代上限不等于收敛；模拟退火结束不等于宏单元合法；导出成功不等于布局合法。报告分别标明算法终止原因、几何检查结论和文件生成结果。

## 7. 验收与风险

软件后续验收要求：指定小例结果可手算、梯度与频域校验通过、合法结果独立检查零违规、固定对象不变、双导出可打开、GUI 不阻塞且取消后可重新启动。基准线长与性能先记录初始值和环境，再测改进，不能直接采用论文宣称的提升比例作为本项目结果。

| 风险 | 影响 | 设计措施 |
|---|---|---|
| 讲义公式排版与术语混用 | 数值求解错误 | 原论文核对、公式勘误、有限差分校验 |
| 原始坐标聚集或越界 | 初始模型无法求解 | 显式初始布局准备、保留原坐标和修正记录 |
| 可放置容量不足 | 合法化无法成功 | 面积预检、区间容量诊断、返回不可行或未找到解 |
| 半百万单元与近两百万引脚 | GUI 卡顿、内存膨胀 | 分块绘制、只读共享拓扑、有界快照和 LOD |
| 第三方版本和数据不匹配 | 接口或加载失败 | 版本锁定、适配层、宏/引脚存在性核对 |

本次文档验收只检查完整性、一致性、链接与测试可判定性；任何未执行实验明确注明“待执行”。
